## Projects

### Project #1: Coffee Roast Classifier with Computer Vision

**Keywords:** Computer Vision, Machine Learning, OpenCV  
**Role:** Machine Learning Engineer

Developed a computer vision system to classify coffee bean roast levels (green, light, medium, dark) using GLCM and LBP texture feature extraction, along with color feature extraction.

Through digital image processing, this system is capable of detecting each coffee bean in an image and assigning classification labels automatically and accurately.

**Project Link:** https://bit.ly/CoffeeBeansClassifier

### Project #2: Number Plate Recognition with Computer Vision

**Keywords:** Computer Vision, Deep Learning, YOLOv8  
**Role:** Machine Learning Engineer

Built an Automatic Number Plate Recognition (ANPR) system that uses a YOLO model to detect license plate locations and OCR technology to read the characters. This system automates real-time vehicle identification for traffic monitoring or smart parking management.

**Project Link:** https://github.com/cakrasyafiq/VehiclePlateDetection
